# KIM DOLCE AI

Chatbot AI premium en Kreyòl Ayisyen, Français et English.

## Installation

1. Installer Node.js 20+.
2. Copier `.env.example` vers `.env`.
3. Ajouter `OPENAI_API_KEY` dans `.env`.
4. Exécuter `npm install`.
5. Exécuter `npm start`.
6. Ouvrir `http://localhost:3000`.

Ne publiez jamais `.env` ou votre clé API dans GitHub.
